# Case-study brief

## Research question

Can a fixed photonic reservoir provide a useful 15-dimensional nonlinear representation for
six-class steel surface-defect classification when only 12, 24, or 48 labels per class are
available, compared with strong classical controls using the same frozen CLIP encoder?

## Decision audience

The case study is prepared for a technical interview with Quanova. Only the candidate's relevant
computer-vision, machine-learning, embedded-AI, and research experience belongs in the package.
Contact details and unrelated private documents are excluded from the repository and Colab assets.

## Deliverables

The interview package contains runnable code/configs, an evidence-traceable Vietnamese report,
an English 16:9 slide deck of about ten slides, speaker notes, Vietnamese Q&A preparation, and an
8–12 week extension plan. A negative or null quantum result remains a valid finding.
